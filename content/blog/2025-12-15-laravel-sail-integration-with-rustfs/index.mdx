RustFS 是面向现代云原生与 AI 工作负载打造的高性能 S3 兼容对象存储系统。Laravel 是全球最受欢迎的 PHP 框架之一，可通过 Laravel Sail 和 Flysystem S3 适配器原生接入 RustFS。

本指南将介绍如何在 **Ubuntu 24.04** 上完成 **Laravel + Laravel Sail + RustFS** 的**端到端集成**。

> Laravel Sail 已新增对 RustFS 的一等支持，参考：https://github.com/laravel/sail/pull/822

* * *

## 架构概览

*   **Laravel Sail** 在 Docker 容器中运行 Laravel 应用
*   **RustFS** 提供 S3 兼容对象存储
*   **Flysystem S3 Adapter** 连接 Laravel 与 RustFS
*   各组件通过标准 **AWS S3 API** 通信

* * *

## 前置条件

*   Ubuntu 24.04 LTS
*   sudo 权限
*   互联网连接

* * *

## 1\. 安装 PHP 8.3

### 1.1 更新系统并安装依赖

```
sudo apt update
sudo apt install -y lsb-release ca-certificates apt-transport-https software-properties-common
```

### 1.2 添加 PHP 仓库（Ondřej Surý PPA）

```
sudo add-apt-repository ppa:ondrej/php
sudo apt update
```

### 1.3 安装 PHP 8.3 与所需扩展

```
sudo apt install -y php8.3   php8.3-cli php8.3-fpm php8.3-mysql php8.3-curl   php8.3-mbstring php8.3-xml php8.3-zip   php8.3-bcmath php8.3-gd
```

### 1.4 验证安装

```
php -v
```

* * *

## 2\. 安装 Docker Engine

Laravel Sail 和 RustFS 都需要 Docker。

### 2.1 移除冲突软件包

```
sudo apt-get remove -y docker.io docker-doc docker-compose docker-compose-v2 podman-docker containerd runc
```

### 2.2 安装 Docker 仓库与 GPG 密钥

```
sudo apt-get update
sudo apt-get install -y ca-certificates curl

sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg   -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

### 2.3 添加 Docker 仓库

```
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

### 2.4 安装 Docker Engine

```
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

### 2.5 验证 Docker 安装

```
sudo docker run hello-world
```

* * *

## 3\. 安装 RustFS（Docker 部署）

在开发和测试环境中，以单节点 Docker 服务方式部署 RustFS。

```
mkdir -p data logs
sudo chown -R 10001:10001 data logs

docker run -d   --name rustfs   -p 9000:9000   -p 9001:9001   -v $(pwd)/data:/data   -v $(pwd)/logs:/logs   rustfs/rustfs:latest
```

*   **S3 API 端点：** http://localhost:9000
*   **管理控制台：** http://localhost:9001
*   **默认凭据：** rustfsadmin / rustfsadmin（除非另行覆盖）

通过 RustFS 控制台创建名为 **`test-bucket`** 的存储桶。

* * *

## 4\. 安装 Composer

```
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php -r "unlink('composer-setup.php');"
sudo mv composer.phar /usr/local/bin/composer

composer -V
```

* * *

## 5\. 使用 Sail 创建 Laravel 项目

### 5.1 创建 Laravel 项目

```
composer create-project laravel/laravel rustfs-laravel
cd rustfs-laravel
```

### 5.2 安装 Laravel Sail

```
php artisan sail:install
```

### 5.3 启动 Sail 环境

```
./vendor/bin/sail up -d
```

* * *

## 6\. 安装 Flysystem S3 适配器

Laravel 需要通过 AWS S3 Flysystem 适配器与 RustFS 通信。

```
./vendor/bin/sail composer require league/flysystem-aws-s3-v3
```

* * *

## 7\. 配置 Laravel 使用 RustFS

编辑项目根目录中的 `.env` 文件：

```
FILESYSTEM_DISK=s3

AWS_ACCESS_KEY_ID=rustfsadmin
AWS_SECRET_ACCESS_KEY=rustfsadmin
AWS_DEFAULT_REGION=us-east-1
AWS_BUCKET=test-bucket

# RustFS S3 API 端点（Linux 上的 Docker 网桥）
AWS_ENDPOINT=http://172.17.0.1:9000

# S3 兼容存储必须启用
AWS_USE_PATH_STYLE_ENDPOINT=true
```

* * *

## 8\. 验证集成（冒烟测试）

此步骤验证 Laravel Sail 与 RustFS 的端到端兼容性，包括写入、读取、存在性检查和延迟测量。

编辑 `routes/web.php` 并添加：

```
use Illuminate\Support\Facades\Route;
use Illuminate\Support\Facades\Storage;

Route::get('/test-rustfs', function () {
    $fileName = 'rustfs-smoke-test-' . time() . '.txt';
    $content = 'Hello RustFS! This is a Laravel Sail integration test.';

    try {
        // 写入对象
        $start = microtime(true);
        Storage::disk('s3')->put($fileName, $content);
        $writeLatency = round((microtime(true) - $start) * 1000, 2);

        // 检查对象是否存在
        $exists = Storage::disk('s3')->exists($fileName);

        // 读取对象
        $readContent = Storage::disk('s3')->get($fileName);

        return response()->json([
            'status' => 'success',
            'file' => $fileName,
            'exists' => $exists,
            'write_latency_ms' => $writeLatency,
            'content_read' => $readContent,
            'driver_config' => config('filesystems.disks.s3'),
        ]);
    } catch (\Throwable $e) {
        return response()->json([
            'status' => 'error',
            'message' => $e->getMessage(),
        ], 500);
    }
});
```

在浏览器中访问：

```
http://localhost/test-rustfs
```

## 总结

Laravel Sail 可以通过标准 S3 API 与 RustFS 无缝集成。PHP 开发者只需少量配置，即可将 RustFS 用作**高性能、自托管的对象存储后端**。

有关集群、TLS、预签名 URL 和生产环境加固等高级主题，请参阅 RustFS 官方文档。
